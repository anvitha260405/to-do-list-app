# To-Do List GUI App

A simple To-Do List application built with Python and Tkinter.

## Features:
- Add tasks
- Mark tasks as done
- Delete tasks
- Saves tasks to a file

## Requirements:
- Python 3.x
- Tkinter (usually comes with Python by default)

## How to Run:
1. Clone the repository.
2. Run the `todo_gui.py` file.
3. Add, edit, mark as done, and delete tasks as needed.
